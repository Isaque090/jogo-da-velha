# 🎮 Jogo da Velha

Um jogo da velha moderno feito com HTML, CSS e JavaScript.

---

## ✨ Funcionalidades

- Sistema de turnos
- Placar em tempo real
- Verificação de vitória
- Verificação de empate
- Reinício automático
- Interface moderna

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 4

---


## 🎯 Objetivo

Projeto criado para praticar lógica de programação, manipulação do DOM, arrays, funções e eventos.

---

## 🖥️ Como executar

1. Clone o repositório:

git clone https://github.com/SEU-USUARIO/jogo-da-velha-js.git

2. Abra o arquivo `index.html` no navegador.
